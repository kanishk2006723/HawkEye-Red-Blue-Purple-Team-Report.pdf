# HawkEye Red, Blue & Purple Team Report

## About

This project is based on the CyberDefenders **HawkEye** lab. It explores the attack from Red Team, Blue Team, and Purple Team perspectives, covering how the attack works, how it can be investigated, and how organizations can improve their detection and response.

## Topics Covered

- Red Team attack simulation
- Blue Team investigation
- Purple Team findings
- MITRE ATT&CK mapping
- IOC analysis
- Detection and mitigation recommendations

## Tools

- Wireshark
- CyberChef
- MITRE ATT&CK
- CyberDefenders
